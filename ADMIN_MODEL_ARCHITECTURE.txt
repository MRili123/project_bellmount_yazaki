  ├─ Option C: REJECT

───────────────────────────────────────
  Model App (model_app.py - PyQt6)
  │
  ├─ DATASET Section
  │  ├─ Load annotations.json (2,847 entries)
  │  ├─ Filter: approved only, date range, quality score
  │  └─ 80/20 train/val split
  │
  ├─ MODEL Page → [TRAIN NEW MODEL] button
  │  ├─ Dialog: Configure training
  │  │  ├─ Epochs: [30]
  │  │  ├─ Batch size: [8]
  │  │  ├─ Learning rate: [0.001]
  │  │  ├─ Augmentation: [✓]
  │  │  └─ Device: Auto (CUDA/CPU)
  │  │
  │  └─ TrainWorker thread:
  │     ├─ DataLoader (train 2,241 + val 560)
  │     ├─ Model: MobileNetV2 + keypoint head
  │     ├─ Loss: MSE + alignment constraint
  │     ├─ For each epoch:
  │     │  ├─ Forward pass (imgs → pred [x1,y1,x2,y2])
  │     │  ├─ Backward pass (loss.backward())
  │     │  ├─ Checkpoint best model
  │     │  ├─ UI update: progress bar, loss curve
  │     │  └─ ETA countdown
  │     ├─ Save: keypoint_cnn.pth, train_history.json, model_meta.json
  │     └─ Emit: finished(metrics)
  │

     ├─ Load best model
     ├─ Run on full dataset

     │  ├─ Mean pixel error
     │  ├─ Distance error
     │  ├─ Accuracy within 10px / 20px
     │  └─ Per-sample error breakdown
     └─ Display results in table


Step 5: INFERENCE (Test)
────────────────────────
  Model App - Test Image Worker
  ├─ Load test image (must be 640×480)
  ├─ Validation:
  │  ├─ Size check (640×480) → error if not
  │  └─ Blur check (Laplacian variance) → warning if blurry
  ├─ Preprocessing:
  │  ├─ Apply threshold (same pipeline as training)
  │  ├─ Resize, normalize to [0,1]
  │  └─ Repeat 3x for 3-channel input
  ├─ Model inference:
  │  ├─ Forward pass → [x1_norm, y1_norm, x2_norm, y2_norm]
  │  ├─ Denormalize to pixel coordinates
  │  ├─ Enforce Y-alignment: y_pred = (y1 + y2) / 2
  │  └─ Compute pixel distance
  └─ Display:
     ├─ Overlay P1/P2 on image (green dots)
     ├─ Draw line between points (yellow)
     ├─ Display distance (X.XX mm)
     └─ Show blur score + quality indicator

================================================================================
                      MODEL ARCHITECTURE DETAILS
================================================================================

KEYPOINT MODEL (MobileNetV2 Backbone)
──────────────────────────────────────

Input:  640×480 grayscale image (thresholded binary)
        ↓
        [Repeat 3x] → 3-channel tensor (3, 640, 480)
        ↓
Backbone: MobileNetV2 (ImageNet pretrained)
        - First conv modified: 3ch input
        - Features frozen initially
        - Output features: 1280ch
        ↓
Custom Head:
        - Dropout(0.2)
        - Dense(1280 → 256)
        - ReLU
        - Dense(256 → 4)     [x1, y1, x2, y2]
        - Sigmoid            [normalized to 0-1]
        ↓
Output: (batch, 4) → normalized keypoint coordinates

Loss Function:
        L = MSE(pred, target) + 0.1 * MSE(y1 - y2)
        Where:
        - MSE: standard regression loss
        - Y-alignment: encourages y1 ≈ y2 (horizontal cables)

Optimizer: Adam (lr=0.001, weight_decay=1e-4)
Scheduler: Cosine annealing (30 epochs)
Device: CUDA (GPU) or CPU


STATE DETECTION MODEL (Planned - 3-class classifier)
─────────────────────────────────────────────────────

Classes:
  - 🔴 No Cable Detected    (0)
  - 🟡 Cable Male Placed    (1)
  - 🟢 Cable Good Placed    (2)

Input: Same preprocessing as keypoint model
Architecture: EfficientNet or ResNet50 (to be determined)
Output: (batch, 3) → class logits → softmax probabilities
Dataset: ~1,247 labeled images (collected by annoteurs)
Training: Balanced class weights to handle imbalance

================================================================================
                    IMAGE PROCESSING PIPELINE
================================================================================

INPUT: BGR color frame from camera (640×480, 8-bit)
│
├─ cv2.cvtColor() → GRAY (640×480, grayscale)
├─ cv2.GaussianBlur() with kernel=5×5
├─ cv2.adaptiveThreshold()
│   Method:  GAUSSIAN_C
│   Threshold: BINARY_INV
│   Block size: 31 (neighborhood)
│   Constant C: 5
├─ cv2.morphologyEx(MORPH_OPEN, kernel=3×3, iterations=1)
│   → Remove small noise
├─ cv2.morphologyEx(MORPH_CLOSE, kernel=3×3, iterations=1)
│   → Fill small holes
│
OUTPUT: Single-channel binary image (0-255)
        White = cable/threads, Black = background

USED FOR: Both training & inference (ensures consistency)

WHY THIS PIPELINE:
  ✓ Adaptive threshold handles lighting variations
  ✓ Inversion emphasizes cable geometry
  ✓ Morphology cleans up noise
  ✓ Deterministic (no random augmentation in pipeline)

================================================================================
                         CACHING STRATEGY
================================================================================

Admin Cache System (admin_cache.json on disk):
┌─────────────────────────────────────────────────────────────────┐
│ Key         │ Timeout │ Refresh Policy                          │
├─────────────────────────────────────────────────────────────────┤
│ "users"     │ 30s     │ Every 30s OR on user create/delete      │
│ "machines"  │ 30s     │ Every 30s OR on machine connect         │
│ "switches"  │ 30s     │ Every 30s OR on switch edit             │
│ "captures"  │ 10s     │ Every 10s (frequent updates) OR refresh │
└─────────────────────────────────────────────────────────────────┘

Benefits:
  ✓ Instant UI response (no loading spinners)
  ✓ Graceful degradation if API down (show cached data)
  ✓ Reduced server load
  ✓ Works offline (read-only mode with cached data)

Drawbacks:
  ✗ Potential stale data (30s delay)
  ✗ Must handle conflicts (local vs server changes)
  ✗ Cache invalidation on bulk operations

Merge Strategy:
  1. Server has authoritative data
  2. Local adds items not in server (but should merge)
  3. Local removes items deleted on server
  4. Local updates items changed on server
  5. File written atomically (JSON with indent for readability)

Switches Management:
